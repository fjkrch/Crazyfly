# Frozen LIF actor specification

The [MaleCNS v1.0 source tables](../data/connectome/README.md) provide neuron annotations, aggregate transmitter predictions, and integer directed connection counts. The three public Feather files and their local SHA-256 hashes are documented there with official download URLs and CC BY 4.0 attribution. A selected simulation circuit is derived from those tables: the raw count is retained as evidence, while the signed, scaled `weight` used by the LIF core is a declared modeling transform. A connection count is not a measured synaptic current or conductance, and a predicted transmitter label is not a measured physiological effect.

The connectome loader requires an explicit manifest; its `pre -> post` edges are evaluated as `W[post, pre]`. Real manifests record source release, extraction, selected neurons, duplicate handling, weight mapping, model constants, and checksums of the derived neuron and edge files. It never substitutes a synthetic graph. The selected circuit is not the complete MaleCNS; its construction rule, interface neuron IDs, and assumptions must remain visible in the generated manifest.

The current MaleCNS circuit can be rebuilt from the copied raw tables using `python scripts/prepare_malecns.py --source-dir data/connectome/raw --output-dir data/connectome` after installing the `.[data]` extra. The converter selects 24 leg-nerve proprioceptive sensory inputs, eight descending inputs, 200 thoracic VNC interneurons, and 24 leg-motor readouts. Sensory/descending/interneuron sources are restricted to predicted `consensus_nt` acetylcholine or GABA. Motor-origin and self edges are excluded; disconnected input candidates are replaced within their declared groups. The resulting 256-neuron, 5,103-edge circuit has 32/32 selected inputs reaching a motor output and 24/24 outputs reached by an input. These are structural path checks, not behavioral results.

Each derived edge retains its raw synapse count. The model weight is `sign × 0.5 × log1p(raw_synapse_count) / sum_pre log1p(count)` for the selected postsynaptic neuron, with ACh assigned positive and GABA negative. The 5,103 edges comprise 3,549 positive and 1,554 negative model weights. This per-post normalization and sign assignment are explicit engineering assumptions. They are held fixed during original-circuit training; degree-preserving rewiring carries an edge's weight with its original source, so the same per-post bound is not guaranteed after rewiring.

For each policy control step, the encoder injects current only into a declared input subset. The LIF core executes the manifest's configured neural substeps, then the decoder reads filtered spikes from a declared output subset. The generic class defaults are `dt=2 ms` and five substeps; the **current real MaleCNS manifest instead sets `dt=4 ms × 5 substeps = 20 ms`**, matching the task control interval. These timings are engineering choices, not measured fly physiology. The actor has no observation-to-action bypass. The separate critic can be trainable.

The current real manifest sets threshold `0.047` and surrogate beta `1.0`, both dimensionless pilot calibrations. Threshold `1.0` gave no spikes; `0.05` became nearly motor-silent after one PPO update. A 100-control-step simulator trace after five guarded updates at `0.047` showed 13/24 original-circuit and 6/24 rewired-circuit motor cells active. Rewiring produced lower interneuron activity in that pilot, so equivalent graph sizes do not imply equivalent firing statistics. Beta `1.0` reduced raw gradient magnitude. A post-step KL rollback guard and a 1e-6 LIF learning rate kept accepted pilot updates below KL 0.05; longer stability validation remains open.

The frozen core stores edge indices, weights, and decay constants as PyTorch buffers, rather than parameters. For the current 256-neuron circuit, it also derives a fixed 256 × 256 dense recurrent matrix from those edges for each policy forward pass. This avoids CUDA `index_add` reduction-order differences that previously made a near-threshold spike differ between PPO collection and replay; the edge list remains the auditable graph, and the derived matrix is rebuilt after checkpoint loading. Frozen-LIF PPO rejects graphs above the current 1,024-neuron dense limit until a deterministic sparse replay backend is validated. Its hard forward spike is thresholded LIF; its backward derivative uses a fast-sigmoid surrogate. This derivative exists solely for optimization. The forward pass is never wrapped in `no_grad` or detached, so gradients can reach the encoder through the fixed core. State per vector environment consists of membrane voltage, hard spikes, filtered spikes, and refractory counter; reset masks change only selected environments. A 60-update, 16-environment simulator pilot completed 1,920 control steps per environment, crossing the first 1,000-step episode reset without a replay mismatch; this is not a full-budget learning result.

The action head uses a tanh diagonal Gaussian. Rollouts retain the bounded sampled action and its transformed-space log probability. The current recurrent PPO reference stores ordered sequences, reset masks, values, actions, and log probabilities and replays the stateful actor with truncated BPTT. Its base Gaussian entropy is an explicitly documented regularizer approximation.

The conventional comparison is a trainable GRU with the same bounded head. The rewiring function swaps destinations, preserving directed in/out degree; weight/sign values remain associated with their original source edge. It reports seed, attempts, and completed swaps. Acute ablation masks only selected neurons' outgoing spikes and keeps their weights untouched; sham and degree-matched random controls are supplied by the evaluation helpers.
